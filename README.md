# منظومة التلخيص التأصيلي والمحاكاة الأسلوبية (`summarization_skill`)

منظومة محلية متكاملة (Local-First) لتحليل النصوص الطويلة وتلخيصها وتطهير أجزائها، مصممة لاستيعاب المحاضرات والكتب والدروس المنهجية (الشرعية، الفكرية، اللغوية، والتقنية) وفق منهجية التقييد الشخصي الناضج، مع تفكيك الفقرات، وصيانة شبكات الاستدلال، ونفي الحشو والاستدعاء الآلي الخارجي بالكلية.

---

## 1. أركان التلخيص التأصيلي الناضج (Core Methodology)

تنهض المنظومة على ستة أركان منهجية مستنبطة من دفاتر التقييد المنهجي المحقق:

1. **الفوائد الاستهلالية (`## فوائد إثرائية:`):** اقتناص الفرائد العقدية والإسنادية والمنهجية الجانبية في مستهل التلخيص قبل الولوج في صلب المادة.
2. **التبويب الفصولي المطابق:** محاكاة التبويب الأصلي للمصنف أو المحاضر بترويسات واضحة (`## ` للمباحث، و`### ` للمطالب).
3. **استيعاب المسائل والتفريعات:** استهلال كل مسألة كلية بنقطة مفردة `•`، وإدراج تفريعاتها وقيودها مرقمة بـ `1-`، `2-`، `3-`.
4. **السبر والتقسيم وإيراد الإشكالات:** صياغة الاعتراضات والأسئلة بأسلوب محكم: `• إشكال: ... والجواب من وجوه: 1- ...`.
5. **صيانة الأدلة وتعيين مناط الاستدلال:** إيراد الشواهد بتخريجها مع التنصيص الصريح على `وجه الدلالة:` في سطر مستقل.
6. **الصرامة الإبستمولوجية والمحاكمات العقلية:** استيعاب الفروق بين النماذج المعرفية، والمناظرات التاريخية، والبراهين المؤسسة، ودفع الدور والتسلسل والتحكم دون بتر كيفي.

### الضوابط التحريرية الحاكمة:
- **الأمانة العلمية التامة (Zero External Hallucination):** حظر تخريج الأحاديث أو عزو الآثار أو إضافة رواة وشروح من الذاكرة الآلية ما لم يتلفظ بها المتحدث صراحة في الأصل.
- **استقلالية الأسطر المطلقة:** أخذ سطر جديد وجوباً بعد كل نقطة (`.`)، وحظر دمج التعليلات في فقرات ممتدة.
- **التطهير من النقط المتتالية:** منع استخدام علامات الحذف والنقط المتتالية (`...` أو `..`) صيانةً للبناء الاستدلالي.
- **فرز الاستطرادات الشفهية:** إسقاط طُرف وممازحات المجلس وأحاديث السفر والسيارة وجوباً، وصيانة الشواهد والمناظرات العلمية.
- **مرجعية النماذج التسعة:** لزوم مطالعة ملف الأمثلة المعتمدة [references/examples.md](.agents/skills/summarization_skill/references/examples.md) قبل التلخيص لضبط السبك والقالب، وحظر محاكاة أي ملخصات سابقة لتفادي توارث الأخطاء.

- **محلية خالصة (Zero External Dependencies):** الاعتماد الحصري على مكتبات بايثون القياسية (`pathlib`, `json`, `re`, `hashlib`, `argparse`).

## 3. أدوات سطر الأوامر (CLI Reference)

### أولاً: سكربت التجزئة والتقطيع (`split_text.py`)
يقسم النصوص الطويلة إلى أجزاء ضمن السعة الفعالة (افتراضياً: 1000 كلمة)، مع اقتناص الفواصل الطبيعية (رؤوس المباحث، أواخر الفقرات، نهايات الجمل)، وتجنب البتر داخل الجداول البرمجية وكتل الأكواد، مع إنشاء بصمة رقمية مركبة لحفظ الاستئناف وتجنب تكرار العمل.

```powershell
python .agents/skills/summarization_skill/scripts/split_text.py <input_file_or_dir> [options]
```

**الخيارات المتاحة:**
- `input`: مسار الملف النصي المراد تقطيعه أو مجلد المعالجة الدفعية.
- `-o`, `--output`: مجلد مخرجات الأجزاء المقسمة (الافتراضي: `all_parts/<اسم_الملف>_parts`).
- `--max-words`: الحد الأقصى لكلمات الجزء الواحد (الافتراضي: `1000`).
- `--min-words`: الحد الأدنى لفتح جزء مستقل جديد (الافتراضي: `500`).
- `-f`, `--force`: فرض إعادة التقسيم وتجاوز التحقق من البصمات السابقة.

**أمثلة الاستخدام:**
```powershell
# تقسيم ملف مفرد
python .agents/skills/summarization_skill/scripts/split_text.py "transcripts/lecture_01.txt" -o "all_parts/lecture_01_parts"

# تقسيم مجلد كامل دفعياً
python .agents/skills/summarization_skill/scripts/split_text.py "transcripts/" --max-words 1200
```

### ثانياً: سكربت دمج التلخيصات وتطهيرها (`compile_summaries.py`)
يدمج أجزاء التلخيصات المتعاقبة في ملف Markdown موحد، مع تجريد ترويسات التوجيه والبرومبتات، وحذف تكرار البسملة والعناوين الرئيسية من الأجزاء اللاحقة، وصيانة العناوين الفرعية الداخلية والشواهد، وإجراء الفحص التنسيقي.

```powershell
python .agents/skills/summarization_skill/scripts/compile_summaries.py [input_dir] [options]
```

**الخيارات المتاحة (4 خيارات حصرية ومقتضبة):**
- `input_dir`: مجلد الأجزاء المفرقة (الافتراضي: `all_parts`).
- `-o`, `--output`: مسار ملف المخرج المدمج النهائي (الافتراضي: `summaries/<اسم_الملف>_summary.md`) أو مجلد المخرجات الأساس في الدمج الدفعي.
- `-c`, `--clean`: الحذف التلقائي الآمن لمجلد الأجزاء المؤقت المنتهي بـ `_parts` إثر نجاح الدمج.
- `--strict-audit`: تفعيل الفحص التنسيقي الصارم؛ ينهي العملية برمز خطأ عند وجود أي عيب هيكلي.

**أمثلة الاستخدام:**
```powershell
# دمج أجزاء مجلد واحد مع التنظيف والتدقيق الصارم
python .agents/skills/summarization_skill/scripts/compile_summaries.py "all_parts/lecture_01_parts" -o "summaries/lecture_01_summary.md" -c --strict-audit

# دمج دفعة مجلدات أجزاء بالكامل
python .agents/skills/summarization_skill/scripts/compile_summaries.py "all_parts" -o "summaries" -c
```
